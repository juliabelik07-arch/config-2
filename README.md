# Инструмент визуализации графа зависимостей для менеджера пакетов (Вариант №3)

## Этап 1. Минимальный прототип с конфигурацией

Реализовано CLI-приложение с возможностью настройки параметров через командную строку.

**Выполненные требования:**
1. Создано консольное приложение с настройкой через аргументы командной строки.
2. Добавлены параметры:
   - `--package` — имя анализируемого пакета;
   - `--repository` — URL-адрес npm Registry;
   - `--test-mode` — включение тестового режима;
   - `--test-file` — путь к файлу тестового репозитория;
   - `--output` — имя выходного SVG-файла;
   - `--max-depth` — максимальная глубина анализа зависимостей.
3. Реализован вывод всех параметров при запуске в формате «ключ — значение».
4. Добавлена обработка ошибок при вводе некорректных параметров.
5. Результат этапа сохранён в Git-репозитории с помощью коммита.

## Этап 2. Сбор данных

Реализовано получение информации о прямых зависимостях npm-пакетов из указанного репозитория.

**Выполненные требования:**
1. Используется формат пакетов JavaScript (npm).
2. Реализовано получение информации о пакете через npm Registry с использованием URL `https://registry.npmjs.org`.
3. Добавлено извлечение списка прямых зависимостей из полученных JSON-данных.
4. Для получения информации используются стандартные средства Python, без применения менеджеров пакетов и сторонних библиотек для сбора зависимостей.
5. Реализован вывод прямых зависимостей заданного пакета на экран.
6. Результат этапа сохранён в Git-репозитории с помощью коммита.

## Этап 3. Основные операции

Реализовано построение графа зависимостей с учётом транзитивных связей.

**Выполненные требования:**
1. Реализовано получение графа зависимостей с помощью алгоритма обхода в глубину DFS без использования рекурсии.
2. Добавлено ограничение глубины анализа с помощью параметра `--max-depth`.
3. Реализована обработка циклических зависимостей.
4. Добавлен тестовый режим, позволяющий использовать JSON-файл с описанием графа вместо обращения к реальному репозиторию.
5. Для тестирования созданы файлы с пакетами, обозначенными заглавными латинскими буквами.
6. Проведена проверка работы программы на различных случаях: обычный граф, граф без зависимостей и граф с циклическими зависимостями.
7. Реализована визуализация построенного графа в формате SVG.
8. Результат этапа сохранён в Git-репозитории с помощью коммита.

## Этап 4. Дополнительные операции

Реализовано определение порядка загрузки пакетов на основе построенного графа зависимостей.

**Выполненные требования:**
1. Добавлен вывод порядка загрузки пакетов для заданного пакета.
2. Реализован алгоритм топологической сортировки для определения порядка загрузки: сначала загружаются зависимости, затем пакеты, которые от них зависят.
3. Проведено сравнение полученного результата с реальным менеджером пакетов npm.
4. Проанализированы расхождения между результатами программы и npm. Они могут быть связаны с ограничением глубины анализа, различиями версий пакетов и особенностями разрешения зависимостей.
5. Проведена проверка работы на тестовых репозиториях с обычными зависимостями, пакетами без зависимостей и циклическими зависимостями.
6. Результат этапа сохранён в Git-репозитории с помощью коммита.

## Запуск программы

Все команды необходимо выполнять из корневой папки проекта:

```powershell
cd "C:\Users\Windows\OneDrive\Desktop\2 работа конф упр"
```

### Этап 1. Минимальный прототип с конфигурацией

```powershell
python -m src.main --stage 1 --package axios --max-depth -1
```

### Этап 2. Сбор данных

```powershell
python -m src.main --stage 2 --package axios --max-depth 2
```

### Этап 3. Основные операции

Запуск с реальным пакетом:

```powershell
python -m src.main --stage 3 --package axios --max-depth 2
```

Запуск в тестовом режиме:

```powershell
python -m src.main --stage 3 --package A --test-mode --test-file test_data/repository.json --max-depth 2
```

Проверка графа без зависимостей:

```powershell
python -m src.main --stage 3 --package A --test-mode --test-file test_data/repository_empty.json --max-depth 2
```

Проверка циклических зависимостей:

```powershell
python -m src.main --stage 3 --package A --test-mode --test-file test_data/repository_cycle.json --max-depth 3
```

### Этап 4. Дополнительные операции

Запуск с реальным пакетом:

```powershell
python -m src.main --stage 4 --package axios --max-depth 2
```

Запуск в тестовом режиме:

```powershell
python -m src.main --stage 4 --package A --test-mode --test-file test_data/repository.json --max-depth 2
```

Проверка циклических зависимостей:

```powershell
python -m src.main --stage 4 --package A --test-mode --test-file test_data/repository_cycle.json --max-depth 3
```

## Результат работы

В результате разработан инструмент визуализации графа зависимостей npm-пакетов. Программа позволяет получать информацию о прямых зависимостях, строить транзитивный граф с помощью нерекурсивного алгоритма DFS, учитывать максимальную глубину анализа, обрабатывать циклы, сохранять граф в формате SVG и определять порядок загрузки пакетов.
